SNIPER PREMIUM WEAR - RAZORPAY + NETLIFY

This is the payment-ready website package. Upload the whole project folder to your existing Netlify site.

Before live payments:
1. Deploy the whole folder.
2. Netlify → Project configuration → Environment variables.
3. Add RAZORPAY_KEY_ID and RAZORPAY_KEY_SECRET.
4. Save and redeploy.
5. Use Razorpay LIVE keys only after Razorpay KYC/business website approval.

Never share RAZORPAY_KEY_SECRET, passwords, or OTPs.
